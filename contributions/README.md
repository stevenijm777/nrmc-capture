# Contribution registry

One JSON file per data contribution, named `<github-user>_<biome-or-world>.json`. The easiest way to
create it is `tools/validate_contribution.py`, which writes it already filled in; the shape is shown
in [`_template.json`](_template.json). No images go here: only the record and the link to the data.

Read [CONTRIBUTING.md](../CONTRIBUTING.md) first.
